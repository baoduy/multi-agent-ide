# Implementation Plan: MagentaTerminal Reuse and Sidebar Terminal

**Branch**: `002-run-feature-hook` | **Date**: 2026-04-11 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/002-specify-terminal-component/spec.md`

---

## Summary

Build a reusable `MagentaTerminal` React component with a `readonly` prop. In **readonly mode**, the component renders app-controlled script output (replacing the inline `<pre>` blocks in the Specify onboarding and upgrade dialogs). In **interactive mode**, the component spawns and connects to a live PTY session via `node-pty` running in the daemon, allowing full keyboard-driven terminal interaction.

The component is used in two places: replacing inline terminal rendering in both Specify dialogs (readonly), and as a new Terminal section below the Legend in the right `ActivityPanel` sidebar (interactive).

---

## Technical Context

**Language/Version**: TypeScript 6.0.2 · Node.js 22 (Electron 41.2.0)  
**Primary Dependencies**:
- `node-pty` — native PTY spawning in daemon (new)
- `strip-ansi@6.0.1` — ANSI escape stripping in daemon before IPC emit (new, CommonJS-compatible)
- `@electron/rebuild` — rebuild `node-pty` native addon for Electron's Node ABI (new, devDependency at workspace root)
- Existing: React 19, Zustand, Zod, lucide-react (`Terminal` icon), existing IPC bridge

**Storage**: In-memory only. `TerminalApplicationService` holds a `Map<sessionId, IPty>`. No database entity needed.  
**Testing**: Vitest (unit). Existing test patterns per CLAUDE.md.  
**Target Platform**: macOS/Linux/Windows desktop (Electron 41). node-pty supports all three; rebuild must target correct ABI per platform.  
**Project Type**: Electron desktop app — monorepo with separate daemon, main, ui, shared packages.  
**Performance Goals**: PTY output chunks forwarded within <100ms; UI `<pre>` auto-scrolls smoothly.  
**Constraints**: Native module (.node binary) requires `asarUnpack` in electron-builder. IPC payload kept small — daemon strips ANSI before sending. `strip-ansi` must be v6 (CJS), not v7+ (ESM-only).  
**Scale/Scope**: One PTY session per sidebar terminal instance (single session per component mount). Multiple concurrent dialog processes (one per repoPath) are already managed by the existing `onboardStore` pattern; this feature adds no new concurrency concern there.

## Implementation Guide (for /speckit.tasks)

Ordered task breakdown for task generation.

### Layer 0 — Shared IPC Schema (packages/shared)

**Task S-1**: Extend `IpcRequestSchema` in `packages/shared/src/ipc.ts` with four new discriminated union variants: `terminal:spawn` `{ cwd: string, cols: number, rows: number }`, `terminal:input` `{ sessionId: string, data: string }`, `terminal:resize` `{ sessionId: string, cols: number, rows: number }`, `terminal:close` `{ sessionId: string }`.

**Task S-2**: Extend `IpcResponseSchema` in `packages/shared/src/ipc.ts` with six new variants: `terminal:spawned` `{ sessionId: string }`, `terminal:input:ack` `{ sessionId: string }`, `terminal:resize:ack` `{ sessionId: string }`, `terminal:close:ack` `{ sessionId: string }`, `terminal:data` `{ sessionId: string, data: string }`, `terminal:exited` `{ sessionId: string, exitCode: number }`.

### Layer 1 — Daemon (packages/daemon)

**Task D-1**: Add `"node-pty": "*"` and `"strip-ansi": "^6.0.1"` to `packages/daemon/package.json` dependencies.

**Task D-2**: Create `TerminalApplicationService` class in `packages/daemon/src/application/TerminalApplicationService.ts`:
- Constructor accepts `bridge: IPCBridge`
- Private `sessions: Map<string, IPty>`
- `spawn(sessionId, cwd, cols, rows)`: calls `pty.spawn(shell, [], { cwd, cols, rows, name: "xterm-color" })`, stores in map, wires `pty.onData()` → strips ANSI → emits `terminal:data`, `pty.onExit()` → emits `terminal:exited` + removes from map
- Shell detection: `process.platform === "win32" ? "cmd.exe" : (process.env.SHELL ?? "/bin/bash")`
- `write(sessionId, data)`: writes to PTY stdin; silently no-ops if session unknown
- `resize(sessionId, cols, rows)`: calls `pty.resize()`; silently no-ops if session unknown
- `close(sessionId)`: calls `pty.kill()`, removes from map
- `closeAll()`: iterates and closes all sessions (daemon shutdown hook)

**Task D-3**: Create `terminalHandlers.ts` in `packages/daemon/src/ipc/handlers/` with `registerTerminalHandlers({ bridge, terminalService })`:
- `terminal:spawn`: generate ULID `sessionId`, call `terminalService.spawn(sessionId, msg.cwd, msg.cols, msg.rows)`, return `{ type: "terminal:spawned", sessionId }`
- `terminal:input`: call `terminalService.write(msg.sessionId, msg.data)`, return `{ type: "terminal:input:ack", sessionId: msg.sessionId }`
- `terminal:resize`: call `terminalService.resize(msg.sessionId, msg.cols, msg.rows)`, return `{ type: "terminal:resize:ack", sessionId: msg.sessionId }`
- `terminal:close`: call `terminalService.close(msg.sessionId)`, return `{ type: "terminal:close:ack", sessionId: msg.sessionId }`

**Task D-4**: Update `DaemonContainer.ts` — add `readonly terminalService: TerminalApplicationService`, instantiate in `static async create()`, call `this.terminalService.closeAll()` in shutdown path.

**Task D-5**: Update `registerHandlers.ts` — import and call `registerTerminalHandlers({ bridge, terminalService: container.terminalService })`.

### Layer 2 — UI Store (packages/ui)

**Task U-1**: Update `ResponseForRequest` in `ipcClient.ts` — add `"terminal:spawn" → terminal:spawned`, `"terminal:input" → terminal:input:ack`, `"terminal:resize" → terminal:resize:ack`, `"terminal:close" → terminal:close:ack`.

**Task U-2**: Create `terminalStore.ts`:
- Zustand store; state: `sessions: Record<string, TerminalSession>`, `subscriptionsReady: boolean`
- `spawn(cwd, cols, rows)`: calls `sendOrThrow({ type: "terminal:spawn", cwd, cols, rows })`, inserts session at `"connecting"`, updates to `"active"` on response; returns `sessionId`
- `write(sessionId, data)`: calls `sendCommand({ type: "terminal:input", sessionId, data })`
- `resize(sessionId, cols, rows)`: calls `sendCommand({ type: "terminal:resize", sessionId, cols, rows })`
- `close(sessionId)`: calls `sendOrThrow({ type: "terminal:close", sessionId })`, sets status `"closed"`
- `appendOutput(sessionId, data)`: appends to `sessions[sessionId].output`
- `setExited(sessionId)`: sets status `"closed"`
- `initializeSubscriptions()`: subscribes `terminal:data` → `appendOutput`, `terminal:exited` → `setExited`

### Layer 3 — MagentaTerminal Component

**Task C-1**: Create `MagentaTerminal.tsx` in `packages/ui/src/renderer/components/common/`:
- Props as defined in `data-model.md`
- **Readonly branch** (`readonly === true`):
  - Header bar: lucide-react `Terminal` icon + `label` text + pulse dot when `status === "running"`
  - `<pre>` output area: dark styling (`#1e1e1e` / `#d4d4d4`, monospace, `pre-wrap`, `overflowY: auto`, `maxHeight`). Auto-scroll via `useRef` on `output` change.
  - Inline success span (`#4ade80`) when `status === "done"` and no error; inline error span (`#f87171`) when `status === "done"` and error
  - No input area; no `terminalStore` subscription
- **Interactive branch** (`readonly === false`):
  - On mount: `terminalStore.initializeSubscriptions()`, then `terminalStore.spawn(cwd ?? process.cwd(), 80, 24)`, store `sessionId` in `useRef`
  - On unmount: call `terminalStore.close(sessionId)` if session active
  - Reads `session = useTerminalStore(s => s.sessions[sessionId])`
  - Renders header bar, `<pre>` output area (same dark styling, auto-scroll), "Connecting…" placeholder while `status === "connecting"`
  - Input row: unstyled `<input type="text">` with monospace font; on Enter → `terminalStore.write(sessionId, value + "\n")`, clear input

**Task C-2**: Verify `MagentaTerminal` is importable via direct path (matches existing `common/` import convention in this codebase; no barrel index needed unless one already exists).

### Layer 4 — Dialog Integration

**Task I-1**: Update `UpgradeSpecifyDialog.tsx` — remove inline terminal header, `<pre>`, `terminalRef`, auto-scroll `useEffect`, and `Terminal` lucide import. Replace with `<MagentaTerminal readonly={true} output={output} status={phaseToStatus(phase, success)} successMessage="Upgrade complete!" errorMessage={error ?? undefined} label={phase === "running" ? "Upgrading..." : phase === "done" ? (success ? "Completed" : "Failed") : ""} />`.

**Task I-2**: Update `OnboardDialog.tsx` — same pattern: remove inline terminal block, add `<MagentaTerminal readonly={true} ... />` with props mapped from `phase`/`success`/`error`.

### Layer 5 — ActivityPanel Integration

**Task A-1**: Update `ActivityPanel.tsx` — add a new `<Section title="Terminal" style={{ flexShrink: 0, borderBottom: "none" }}>` after the Legend section (last child of the outer `<div>`); render `<MagentaTerminal readonly={false} cwd={activeRepoPath ?? undefined} maxHeight={200} />` inside it.

### Layer 6 — Build Configuration

**Task B-1**: Update `electron-builder.yml` — add:
```yaml
asarUnpack:
  - "**/node_modules/node-pty/**"
```

**Task B-2**: Update workspace root `package.json` — add `"postinstall": "electron-rebuild -f -w node-pty"` to scripts; add `"@electron/rebuild": "*"` to devDependencies.
